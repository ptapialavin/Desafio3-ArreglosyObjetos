# Desafío 4 - Inmobiliaria

Proyecto realizado para **Desafío Latam**, carrera **Desarrollo Full Stack**, curso **JavaScript para la Web**, módulo **Arreglos y Objetos**.

Aplicación web que renderiza de forma dinámica un listado de propiedades inmobiliarias (en venta y en alquiler) a partir de arreglos de objetos, utilizando manipulación del DOM.
